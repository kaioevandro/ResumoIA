# Resumo IA — descrição para inscrições de créditos

Use este texto como base ao preencher formulários. Adapte o provedor e os valores ao programa.

## O que é o projeto

O Resumo IA é uma ferramenta simples, feita por um desenvolvedor individual, para resumir textos longos, extrair tópicos e listar tarefas. O público são estudantes, freelancers e pequenas equipes que lidam com atas, artigos e documentos.

## Como funciona

- Entrada: texto colado na interface web ou arquivo `.txt` na linha de comando.
- Processamento: uma chamada à API de IA, com instrução de resumo em português.
- Saída: resumo curto, tópicos ou resumo + tarefas.

## Por que precisa de créditos de API

Cada resumo consome tokens de entrada (o texto original) e de saída (o resumo). O projeto usa modelos leves por padrão — por exemplo, `gpt-4o-mini` na OpenAI ou `claude-haiku-4-5` na Anthropic — justamente para manter o custo por resumo baixo e previsível.

Os créditos seriam usados para:
1. Testar o produto com textos reais e medir qualidade dos resumos;
2. Medir custo médio por resumo e por dia de uso;
3. Validar se o projeto vale a pena manter e evoluir, antes de qualquer gasto próprio.
